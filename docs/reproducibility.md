# Reproducibility

## Available without EDA access

Read the Markdown documents and the original SVG hierarchy diagram. GitHub renders the conceptual Mermaid architecture. These artifacts document scope and evidence; they do not simulate the processor.

## Authorized design environment

The source configuration references NC State FreePDK45. The archive uses Virtuoso/OpenAccess design libraries, Calibre-oriented checking configuration, a VCS-based reference simulation flow, and synthesis/Innovus physical-design infrastructure. Availability of these files does not establish successful use of every tool.

Reproducing the implementation requires legitimate tool access, the exact permitted PDK/model versions, course-authorized source, and a suitable Linux environment. Obtain dependencies through their official or institution-approved distribution. No license-server configuration, PDK payload, native database, reference RTL, test program, or course build script is redistributed here.

Once permission is documented, a future reproduction guide should pin dependencies, identify the final top cell, separate schematic and extracted verification, and explain commands using portable paths. This draft does not promise an open-source build or offer an untested replacement flow.
